### Added

- Offline `eventabi diff`, `check`, and `validate` commands.
- Canonical event signatures, Keccak topics, tuple/array normalization, and conservative overload matching.
- Validated consumer manifests with decoded and topic-only compatibility rules.
- Deterministic human, JSON, Markdown, and GitHub annotation reports.
- Working ABI examples, a Foundry integration example, documentation, and Rust CI.
