# Foundry integration

From this directory, run `forge build`, then
`eventabi check --manifest .eventabi/manifest.yaml` (expected exit 1).
The baseline has two parameters; the compiled event adds `referenceId`.
Foundry is only needed to compile Solidity. Every other example uses committed JSON.

For an entirely offline artifact-loading demonstration without Foundry, run:

```bash
eventabi check --manifest .eventabi/manifest-snapshot.yaml
```

This also returns 1. `proposed-artifact.json` is an illustrative ABI snapshot,
not compiler-generated bytecode. The main manifest still reads the real
`out/Payments.sol/Payments.json` produced by `forge build`.
